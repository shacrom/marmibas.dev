Mi entrada en Capgemini fue como desarrollador back-end en un proyecto basado en microservicios Spring Boot apoyados sobre una base de datos relacional. El día a día consistía en evolucionar y mantener servicios Java, modelar el dominio en la BBDD y asegurarme de que los distintos microservicios encajasen entre sí de forma consistente.

Esta etapa me sirvió para consolidar mi base en Java y Spring Boot dentro de un entorno corporativo: trabajar con repositorios compartidos, branching estable, code reviews y pipelines de integración. La parte más interesante fue entender cómo se reparte la responsabilidad entre microservicios y cómo cada decisión de modelado en la BBDD impacta en los contratos que ofrecen al resto del sistema.

Fue la antesala natural a mi siguiente rol full stack, donde mantendría el mismo backend pero sumando la capa Angular del lado cliente.
