Mi entrada en Capgemini fue como desarrollador backend en un proyecto basado en microservicios Spring Boot apoyados sobre una base de datos relacional. El día a día consistía en diseñar y construir servicios Java, modelar el dominio en la base de datos y asegurar que las distintas piezas encajaran entre sí de forma consistente.

Esta etapa me sirvió para consolidar mi base en Java y Spring Boot dentro de un entorno corporativo: trabajar con repositorios compartidos, hacer revisiones de código en equipo y entender cómo se reparte la responsabilidad entre microservicios. Fue la antesala natural a mi siguiente rol full stack en la misma empresa, donde pasaría a trabajar también la capa Angular del lado cliente.
