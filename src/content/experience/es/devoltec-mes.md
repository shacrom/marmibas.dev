En Devoltec desarrollé un MES: un software que conecta máquinas, operarios y materiales en tiempo real dentro de una fábrica. Pensado para adaptarse a industrias muy distintas —desde bolsas hasta señalización— sin reescribirlo cada vez.

- Construí el sistema completo: pantallas de planta, conexión con máquinas y base de datos de trazabilidad.
- Diseñé el flujo de órdenes de fabricación, asignación de máquinas y materiales.
- Integré sensores en tiempo real para seguir el estado de cada línea de producción.
