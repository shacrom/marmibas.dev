Tras la etapa de frontend en Cleverpy, me incorporé al equipo de backend. El trabajo combinaba dos frentes: por un lado, traducir lógica existente en Python a Java para integrarla en los servicios principales; por otro, mantener y evolucionar código Java apoyado en Spring, con persistencia sobre PostgreSQL.

Pasar de un lenguaje a otro me obligó a entender bien la intención del código original antes de tocar nada y a buscar el equivalente correcto en Java sin arrastrar costumbres propias de Python. Fue también mi primer contacto serio con GitFlow trabajando en equipo, lo que me dio orden a la hora de organizar ramas, abrir pull requests y mantener la integración limpia con el resto del proyecto.
